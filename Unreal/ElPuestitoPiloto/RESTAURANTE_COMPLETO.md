# Restaurante completo

Proyecto Unreal Engine 5.8 para la simulacion visual del restaurante El Puestito. El mapa inicial es RestauranteNoche; abre ElPuestitoPiloto.uproject desde Unreal Editor.

Los recursos fuente usados en las correcciones estan en SourceAssets. Las herramientas estan en Tools. Los recursos Unreal de Content se conservan con Git LFS.
